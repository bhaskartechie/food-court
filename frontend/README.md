## Frontend - Society Food Platform

This folder contains the React PWA frontend for the Society Food Platform.

Quick start

1. Install dependencies

```bash
cd frontend
npm install
```

2. Start dev server

```bash
npm start
```

3. Build for production

```bash
npm run build
```

Useful routes

- `/` - Home
- `/login` - Login / Registration (OTP)
- `/sellers` - Browse sellers
- `/menu/:sellerId` - Seller menu
- `/orders` - Your orders (requires login)
- `/profile` - Your profile
- `/seller/dashboard` - Seller dashboard (seller accounts)

This frontend mirrors the features described in the repository README.
